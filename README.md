# Лабораторная работа №5 (Вариант 4): Менеджер списка покупок (Model-View + делегат)

**Цель работы:** Освоить архитектуру Model-View в Qt на практике: научиться отделять данные (`QStringListModel`) от их отображения (`QListView`), реализовать базовые операции CRUD (добавление, удаление, очистка) и создать кастомный делегат для редактирования элементов по двойному клику.

## 🛠️ Реализованный функционал
В приложении реализована классическая архитектура **Model-View-Delegate (MVD)**:
- **Модель:** `QStringListModel` — единственный источник данных.
- **Представление:** `QListView` — отображает данные и слушает сигналы модели.
- **Делегат:** `PurchaseDelegate` (наследник `QStyledItemDelegate`) — отвечает за кастомную отрисовку (зеленая точка-маркер и рамка) и предоставляет `QLineEdit` для редактирования ячейки по двойному клику.

### Операции CRUD:
- **Добавление:** ввод текста в поле и нажатие кнопки «Добавить» (или клавиши Enter).
- **Удаление:** выделение элемента и нажатие «Удалить выделенное» (кнопка активна только при наличии выделения).
- **Очистка:** полная очистка списка кнопкой «Очистить».

## 🚀 Инструкция по сборке и запуску
1. Откройте файл `lab5.pro` в **Qt Creator**.
2. Нажмите **Сборка → Очистить всё** (Clean All).
3. Нажмите **Сборка → Выполнить qmake** (Run qmake).
4. Нажмите **Сборка → Пересобрать** (Rebuild).
5. Запустите приложение (зеленая стрелка `Run`).
6. Для просмотра логов откройте вкладку **Application Output** (Вывод приложения).
